Student Tracking System

A console-based student tracking application I developed while learning Python.

Features

Add, list, search, and delete students

Update student grades

Calculate average grades

Find the highest-performing student

Sort student records

Usage

Python 3 must be installed on your computer. Download the Python file from this repository and run it with Python. Enter the corresponding menu number to select an action.

Why I Built This Project

I created this project to practice Python basics, including conditions, loops, lists, and functions.
